Quiet Numbers

A calm, honest number puzzle for iPhone, iPad and Mac.

Clear the board by pairing numbers that are equal or add up to ten. Pairs can be neighbours, sit on the same line across cleared cells, or follow on from the end of one row to the start of the next. Run out of pairs and + copies what's left to the end of the board.

  • No ads. No purchases. No subscriptions.
  • No data collected: no accounts, no analytics, no tracking.
  • A new daily challenge, the same board for everyone.
  • Game Center leaderboards and achievements, if you want them.
  • Works fully offline.
  • Themes and styles earned by playing, never sold.
